# RolesUsers
Лабораторная: авторизация и переход к формам по роли (Entity Framework, Windows Forms).

1. В SSMS выполнить `SQL/User_Data.sql` (сервер `.\SQLEXPRESS`).
2. Открыть `RolesUsers.sln` в Visual Studio и нажать F5.
3. Логины и пароли: log1/pas1 (Manager), log2/pas2 (Seller), log3/pas3 (Director), log4/pas4 (Seller), log5/pas5 (Manager).
